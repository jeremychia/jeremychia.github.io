
# jeremychia.github.io

Jeremy Chia's personal website — a portfolio showcasing my work in finance transformation, data analytics, and technology.

🌐 **Live site:** [jeremychia.github.io](https://jeremychia.github.io)

## About

This website features:
- **Blog** — Articles on data analytics, text mining, career reflections, and finance transformation
- **Projects** — Showcase of technical and professional projects
- **Publications** — Academic research and publications
- **Speaking** — Conference talks and presentations

Built with [Jekyll](https://jekyllrb.com/) using the [Awesome Jekyll Theme](https://github.com/a-chacon/awesome-jekyll-theme).

## Local Development

### Prerequisites

1. Install Ruby. See [Jekyll installation guide](https://jekyllrb.com/docs/installation/) for instructions.
2. Install Jekyll and Bundler:
   ```sh
   gem install jekyll bundler
   ```

### Running Locally

```sh
# Install dependencies
bundle install

# Start the development server
bundle exec jekyll serve --baseurl ""
```

Open the website at http://localhost:4000

### Adding Content

- **Blog posts:** Add markdown files to `_posts/` with format `YYYY-MM-DD-title.md`
- **Projects:** Add markdown files to `_projects/`
- **Publications:** Add markdown files to `_publications/`
- **Speaking:** Add markdown files to `_speaking/`
