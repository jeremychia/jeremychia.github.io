How three friends used Python, dbt, LLMs, and Render to build Par-leh-Mate — a resource for understanding Singapore's parliament.

## The Motivation

Parliamentary data in Singapore wasn't easily accessible for researchers, journalists, or citizens. We wanted to change that.

## The Build

- **Data Extraction** — Python scripts to scrape parliamentary records
- **Data Transformation** — dbt models to structure and clean the data
- **Data Visualisation** — Streamlit app for exploration

## The Stack

Python · dbt · LLMs · Render · Streamlit
