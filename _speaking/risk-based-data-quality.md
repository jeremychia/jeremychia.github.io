How we transformed data testing at Vinted from reactive firefighting to a proactive, risk-based framework using materiality concepts from accounting.

## The Problem

Data engineers at Vinted used to wake up on weekends to a barrage of pipeline error messages. Overly strict tests were breaking critical pipelines, leading to low confidence in data.

## The Solution

We introduced a risk-based testing framework inspired by financial auditing:

- **Materiality thresholds** — Focus on issues that truly impact data perception
- **Risk matrix** — Prioritise tests based on impact and frequency  
- **Change management** — Used the trans-theoretical model to get stakeholder buy-in

## The Result

- Reduced misstatement risk from €40M to €4M
- Caught €1.6M in carrier overcharges
- Engineers no longer dread weekend alerts
